# V1 Roadmap

0. Foundation — repo boots, CI, preview, Supabase connection/RLS.
1. Capture — auth, inbox, raw preservation.
2. Structure — validated AI output, editable normalized fields, version history, AI audit.
3. Score — deterministic score + confidence + evaluation snapshots.
4. Connect — embeddings, nearest-neighbor candidates, relationship classifier, merge/shared-capability suggestions.
5. Prioritize — portfolio ranking, filters, decision queue, cheap validation suggestions.
6. Execute — idea -> project, milestones, tasks, validation metrics.
7. Learn — actuals, prediction-vs-actual, calibration analytics.

V1 exit: at least 100 real ideas complete capture -> structure -> connect -> prioritize.
